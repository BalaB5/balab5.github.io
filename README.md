### 1. 🔍 DocuQuery AI — Smart Requirement & Project Document Search Engine
An intelligent semantic retrieval and requirement analysis engine tailored for software engineering teams, product managers, and QA engineers.

#### Key Features:
- **Semantic Requirement Search**: Utilizes dense vector embeddings to search across PRDs, SRS, technical specifications, and architecture decision records (ADRs) by contextual intent rather than plain keywords.
- **Requirement Traceability Matrix (RTM)**: Automatically links user stories and system requirements to test cases and architecture components.

### 2. 🤖 HR AI Assistant — Real-Time Model Context Protocol (MCP) Server Integration
An enterprise-grade autonomous AI assistant powered by the **Model Context Protocol (MCP)**, connecting LLM agents directly with live HRMS databases, salary structures, and employee lifecycle data.

#### Key Features:
- **Model Context Protocol (MCP) Architecture**: Implements standard MCP client/server interfaces to expose HR databases as callable tools for LLMs.
- **Real-Time Salary & Compensation Analytics**: Queries live payroll records, compensation bands, market parity percentiles, and performance bonuses with microsecond response times.
- **Live Employee Lookups**: Retrieves employee department, manager hierarchy, tenure, skills, and leave balances on demand.
- **Role-Based Access Control (RBAC)**: Enforces privacy safeguards ensuring compensation data is strictly accessible based on authenticated caller roles.
- **Autonomous Tool Orchestration**: Multi-step reasoning where the agent plans, selects tools, verifies parameters, and synthesizes answers with source citations.

#### Architecture Flow:
```
[ User Query / Prompt ]
         │
         ▼
[ LLM Agent (Claude / GPT-4o) ]
         │ (Tool Calling via MCP)
         ▼
[ MCP Server: hrms-database ]
   ├── Tool: fetch_employee_details(id)
   ├── Tool: fetch_employee_salary(id, role_auth)
   └── Tool: get_compensation_benchmarks(dept, level)
         │
         ▼
[ Enterprise HRMS / PostgreSQL DB ]
         │ (Real-Time Encrypted Data)
         ▼
[ Synthesized Natural Language Response + Visual Analytics ]
```

#### Tech Stack:
- **Protocol**: Model Context Protocol (MCP)
- **Backend & Tools**: Python, TypeScript, FastAPI, Node.js
- **Database**: PostgreSQL / MySQL / SQLite HRMS
- **Security**: OAuth 2.0, JWT, Role-Based Access Control (RBAC)
